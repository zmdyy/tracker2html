# AI 物理视频分析器 V1.10

本版本新增“旋转测量”模式（单摆/圆周运动），并持续优化数据处理与图表分析体验。

## V1.7 更新

- 数据页重构为“总览 → 数据处理流程 → 数据表”的阅读路径。
- 增加总位移、竖直位移、最大速度、最大加速度、最大动能、机械能变化等关键指标。
- 明确显示视频原始帧数、实际采样点数、采样间隔和平滑程度，避免把“采样点”误解成视频帧数。
- 数据处理流程可视化：视频帧 → 采样 → 平滑 → 微分 → 能量。
- 数据表增加：样本号、视频帧号、时间、x、y、沿轨位移 s、速度、加速度、动能、机械能。
- 数据表支持分页；点击数据行可让视频跳到对应帧，方便“视频 ↔ 数据”核对。
- 图表页增加课堂常用预设：位移－时间、速度－时间、加速度－时间、机械能－时间。
- XOY 平面轨迹保持独立显示，不再要求用户手动选择 X/Y 才能看到基本运动轨迹。
- 曲线图增加悬停提示，可查看具体帧、时间和值。
- 图表自动根据所选物理量显示对应解释文字。
- 保留 CSV、JSON、实验分析摘要导出。

## 图表页显示优化（V1.7 增强）

- 图表页改为“双栏主图 + 迷你趋势总览”布局：XOY 平面轨迹与物理量关系曲线并排显示。
- 新增“各物理量随时间变化总览”：x、y、s、v、a、Ek、Ep、Em 八张迷你面积图共用同一时间轴，趋势一眼可比。
- 迷你图显示峰值、最小值、最大值；悬停出现十字准线并实时显示数值；点击任一张即在主图中放大分析。
- 主图增加曲线下面积填充和悬停十字准线，趋势方向更直观。
- 当前选中的物理量在迷你图网格中以高亮边框标出，与预设按钮、坐标选择保持同步。

## 图表页显示优化（V1.8）

- ① XOY 平面轨迹放大显示（画布加高），并叠加“频闪分析”：按等时间间隔在轨迹上标出频闪点与每段位移 Δs，类似打点计时器纸带，可一眼判断运动类型。
- 频闪间隔可选“自动”（按数据时长推荐 5~10 段）或 0.02~1 s 手动指定；对轨迹做等时间重采样（二分查找 + 线性插值），不依赖原始采样点。
- 新增“频闪纸带”条带图：频闪点按累计位移线性排布，显示每段位移数值与相邻段增量 Δ(Δs)，点距大小直观反映运动快慢。
- 支持手动指定分析时间范围：① 工具行中的“时间 __ ~ __”输入框限定频闪分析的起止时刻（留空自动、只填一端自动补全、越界自动裁剪到数据范围）；自动档的频闪间隔按新的时间跨度重新选取，纸带与判读结论随窗口即时更新。
- ① 频闪时间范围与 ② 关系曲线横轴（时间）双向同步：任一侧修改都会同步到另一侧；在 ② 图上框选放大也会同步时间窗口；切换横轴回到“时间”时自动带回已设的时间窗口；“时间自动”/“自动范围”任一按钮都会同时清空两侧。
- 自动判读运动类型：点距接近相等 → 匀速；增量接近相等 → 匀加速并估算 a = Δ(Δs)/Δt²；点距变小 → 减速；否则提示规律不明显。
- 轨迹图改为等比例缩放并铺满画布（x、y 每米像素相同），宽屏下不再有大片留白；终点标记靠近边界时自动翻转避免裁切。
- ② 物理量关系曲线支持手动修改横轴、纵轴显示范围：输入框留空即自动；只填一端则另一端自动；当前无数据点时给出居中提示。
- 支持在主图上直接拖动框选放大：框选区域自动换算为坐标范围并填入输入框，“自动范围”按钮一键恢复。
- 切换物理量、点击迷你图或预设时自动清除手动范围，避免误看空图。

## 视觉识别改进（V1.9）

- 不再只识别蓝色小车：点击目标中心后，程序会学习该目标的颜色，支持蓝、红、绿、白、灰、黑等任意颜色。
- 颜色模型改用色相圆周均值，修复红色/紫色等跨越 0/1 的颜色被平均成错误颜色的问题。
- 彩色目标按色相/饱和度/明度匹配；低饱和或暗色目标改用归一化 RGB 色度/亮度匹配。
- 跟踪锚点由外接框中心改为按匹配强度加权的质心，目标被部分遮挡时更稳定。
- 模板匹配改为“预测位置逐像素精搜 + 大步长兜底 + 亚像素抛物线拟合”，定位更准。
- 修复起始帧错位：从点选目标的那一帧开始跟踪，不再假设目标在第 0 帧的位置，中段点选也能正确建立轨迹。
- 连通域最小面积阈值随视频分辨率自适应，小分辨率画面不再漏检。

## 运行

推荐使用本地 HTTP 服务器运行：

```bash
python -m http.server 8000
```

然后打开 `http://localhost:8000/`。

## 旋转测量（V1.10）

- 新增独立的“旋转测量”模式：① 面板点“旋转测量”，先点击固定点（悬挂点/圆心），再点击运动物体（摆锤/小球），即可输出旋转运动学数据。
- 场景支持：单摆（摆角，竖直向下为 0）、圆周运动（极角，向右为 0、逆时针为正）。
- 输出：连续极角 θ(t)（转过 2π 不跳变）、角速度 ω(t)、半径 r(t)、切向/径向速度分解、自动周期（单摆零穿法 / 圆周转过 2π 计圈法）。
- 数据表/CSV/JSON 同步新增 θ、ω、r、vt、vr 列；图表与迷你图支持对应曲线。
- 视频可叠加固定点与半径参考线（复选框控制）。

## 旋转测量小目标与标定引导（V1.10.1）

- 微小物体（金属小球等占画面比例很小的目标）中心更精准：旋转测量中点选目标使用 1px 步长的精密搜索与收紧的颜色采样，跟踪锚点改用色块几何中心（包围盒中心），不受金属表面高光随视角漂移的影响。
- 进入旋转测量、记录固定点、“建立轨迹”等环节都会提示：实际尺寸结果（r / vt / vr）需先完成 ② 标尺校准；未标定时“建立轨迹”也有旋转专属提示。
- 直线/小车跟踪逻辑完全不变（改进仅在旋转测量模式内生效，所有引擎新增参数均有默认值）。

## 单摆专用跟踪与圆弧约束（V1.10.2）

- 新增「单摆小球跟踪」跟踪方式（推荐单摆/圆周），进入旋转测量时自动选中；对金属/灰色小球尤其可靠。
- 点选小球时：颜色识别失败会**自动回退模板匹配**吸附到目标；旋转模式下点击反馈升级为“目标已锁定（含半径 px）/ 未找到合适目标+建议”；视频上叠加球径识别圈。
- **圆弧约束**：跟踪时利用“球心距悬挂点近似恒定”的物理约束，候选点偏离悬挂点半径环超过 40% 直接排除——标尺、绿色挡板、金属杆、反光点等背景干扰不再把轨迹带偏。
- 修复既有引擎 bug：候选中心 x/y 混用同一字段（bbox 模式 y 误取 cx）；`trackingModeNote` 说明文字此前因 els 缺字段从未更新。
- 直线小车/普通大球跟踪保持原逻辑（`pivot`/`pivotRadius` 为可选参数，仅旋转模式传入）。
